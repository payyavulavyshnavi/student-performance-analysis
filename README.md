\# Student Performance Analysis



\## Objective

The objective of this project is to analyze student attendance,

study hours, internal marks, and final examination performance.



\## Dataset

The dataset contains student performance information such as:

\- Attendance

\- Study Hours

\- Internal Marks

\- Final Marks



\## Tools Used

\- Python

\- Pandas

\- Matplotlib

\- Jupyter Notebook

\- Git

\- GitHub



\## Analysis Performed

\- Basic data exploration

\- Missing-value handling

\- Duplicate removal

\- Categorical encoding

\- Attendance versus final marks visualization
